# hero-split

Custom **hero** block. Purpose: Page-top hero with H1, subheading and CTA on one side and an image beside it (not behind it).

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: Row 1: image. Row 2: H1 title, subheading paragraph, CTA link. A single row with two cells (text | image) also works.

## Supported variations

No variations.
