# hero-split

Custom **hero** block. Purpose: Page-top hero with H1, subheading and CTA on one side and an image beside it (not behind it).

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: Row 1: image. Row 2: H1 title, subheading paragraph, CTA link. A single row with two cells (text | image) also works.

- The first link-only paragraph becomes the green primary CTA (unless the author already formatted it as a button); further link paragraphs render as text links beside it.
- Text-only hero: if a `video` block follows it in the same section, the video (and a single caption paragraph after it) is moved into the hero media column, matching the source copy-beside-video layout.

## Supported variations

No variations.
