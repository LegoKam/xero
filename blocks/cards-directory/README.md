# cards-directory

Custom **cards** block. Purpose: Directory/detail cards with a heading, short description and a list of links (e.g. regions linking to the advisor directory, certification learning paths).

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: One row per card; cell 1 optional image; cell 2 heading, optional description paragraph, then links (a bulleted list of links or one link per paragraph).

## Supported variations

No variations.
