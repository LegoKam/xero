# cards-testimonial

Custom **cards** block. Purpose: Star-rated customer review cards from review sites (e.g. Trustpilot, Capterra).

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: One row per card; cell 1 optional review-site logo image with optional source label paragraph (e.g. Trustpilot); cell 2 rating paragraph ("5 out of 5 stars", rendered as stars), quote paragraph(s), bold reviewer name paragraph, optional business/role paragraph.

## Supported variations

No variations.
