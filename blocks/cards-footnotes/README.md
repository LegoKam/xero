# cards-footnotes

Custom **cards** block. Purpose: List of footnotes / sources for claims made on the page.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: One row per footnote; single cell with superscript marker and source text. A final row can hold a source link.

No variations.
