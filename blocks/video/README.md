# video

Custom **video** block. Purpose: Embedded video (YouTube, Vimeo, Wistia, Brightcove or mp4) with optional poster image.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: Row 1: poster image (optional); Row 2: link to the video URL. Poster and link may also share one cell.

## Supported variations

| Variation | Option class |
| --- | --- |
| Autoplay | `autoplay` |
