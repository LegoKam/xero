# columns-intro

Custom **columns** block. Purpose: Section introduction with a large heading on the left and supporting copy on the right.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: One row with two cells: H2 heading | paragraph(s) with optional link.

Optional popover: in the body cell, a plain-text paragraph (the trigger label, e.g. "Inventory") followed by a paragraph that is only bold text (the popover title) becomes an icon button that opens a modal. Everything after the title (paragraphs, list with bold item titles, a final link rendered as a blue button) moves into the modal.

A decorative hand-drawn arrow is drawn under the heading on desktop (CSS only).

No variations.
