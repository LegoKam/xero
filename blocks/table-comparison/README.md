# table-comparison

Custom **table** block. Purpose: Tier or plan comparison table showing which benefits each tier includes.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: First row: empty cell then column names (e.g. Bronze | Silver | Gold | Platinum). Following rows: benefit label then one cell per column containing Included or Excluded (rendered as tick/cross icons; other text is shown as-is).

- Row label with a description: write the label as the first paragraph and the description as a second paragraph; the description becomes a toggleable info tooltip.
- Value with a note: write two paragraphs (e.g. `For 5 users` / `$5 per additional user`); the second is styled as a secondary note.
- Wide tables scroll horizontally on small screens with a sticky label column and scroll buttons.
