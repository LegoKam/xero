# table-comparison

Custom **table** block. Purpose: Tier or plan comparison table showing which benefits each tier includes.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: First row: empty cell then column names (e.g. Bronze | Silver | Gold | Platinum). Following rows: benefit label then one cell per column containing Included or Excluded (other text is shown as-is).
