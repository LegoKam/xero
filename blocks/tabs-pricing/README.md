# tabs-pricing

Custom **tabs** block. Purpose: Tabbed pricing panels, each tab can hold several plan cards.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: One row per tab: cell 1 tab label, cell 2 panel content. Inside a panel start each plan with an H3 plan name, then the price as a bold paragraph, notes, description, list and Buy now / Learn more links. Content before the first H3 becomes the panel intro.

## Supported variations

No variations.
